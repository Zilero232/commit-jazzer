Fuzzy type search

43 built-in types with emoji. Type `f` and get `feat` and `fix`; search by description or `:shortcode:` too.

Valid Conventional Commits

`type(scope)!: ✨ title`, a wrapped body and `BREAKING CHANGE:` / `Closes #12` footers, checked against commitlint in the tests.

CLI, git hook or Commitizen

Run `jazzer`, let `git commit` ask through `prepare-commit-msg`, or keep using `git cz`.

Scripts and CI

Every answer is a flag: `jazzer -t fix -m "handle empty input"`. Without a terminal nothing is asked.

Fits your setup

Scopes and limits from your commitlint config, type and ticket from the branch name, aliases for frequent commits.

Typed config, 13 languages

JSON, TypeScript, JavaScript or `package.json`, with a JSON Schema for autocompletion. Prompts in English, Russian, German, Chinese and 9 more.
